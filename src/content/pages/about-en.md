JamSite is a hybrid boilerplate that bridges static site generation with modern frontend technologies. It unites Astro's content management power, Svelte 5's reactive component architecture, and Tailwind CSS 4's design system under a single roof.

## Fast

Static HTML + islands. Lighthouse 95+ score.

## Multilingual

i18n is baked in. Adding a new language is just adding files.

## Zero Config

Build and git push. CI/CD optional.

## Modern UI

Reactive components with Svelte 5 + Tailwind 4.

## Technology Stack

Astro 5, Svelte 5, Tailwind CSS 4, Fuse.js
