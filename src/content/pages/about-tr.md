JamSite, statik site üretimi ile modern frontend teknolojilerini birleştiren hibrit bir boilerplate projesidir. Astro'nun içerik yönetimi gücünü, Svelte 5'in reaktif bileşen mimarisini ve Tailwind CSS 4'ün tasarım sistemini tek bir çatı altında toplar.

## Hızlı

Statik HTML + islands. Lighthouse 95+ puan.

## Çok Dilli

i18n mimariyle doğar. Yeni dil eklemek için sadece dosya eklenir.

## Sıfır Yapılandırma

Build al, git push. CI/CD isteğe bağlı.

## Modern UI

Svelte 5 + Tailwind 4 ile reaktif bileşenler.

## Teknoloji Yığını

Astro 5, Svelte 5, Tailwind CSS 4, Fuse.js
