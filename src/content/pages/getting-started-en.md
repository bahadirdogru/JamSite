Set up JamSite in minutes and start customizing.

## Requirements

- **Node.js** (v18+) — [Download](https://nodejs.org/)
- **Git** — [Download](https://git-scm.com/)

## Installation

```bash
# Clone the project
git clone https://github.com/bahadirdogru/JamSite.git

# Install dependencies
cd JamSite && npm install
```

## Development

Run the Astro dev server:

```bash
npm run dev
```

Production build:

```bash
npm run build
```

## Deployment

Run `npm run build` and deploy the `dist/` output to GitHub Pages or any static host. Without GitHub Actions, build locally and push the `dist/` contents to a gh-pages branch.
